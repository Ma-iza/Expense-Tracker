# Finance Tracker

A simple finance management system built using Flask and SQLite to help users manage cash and bank transactions separately. This project was created to practice full-stack web development while solving a real-world finance tracking problem.

## About
This project was inspired by my dad's need for a simple way to manage daily cash and bank transactions. I decided to build it as a learning project while exploring Flask, SQL, and full-stack web development.

## Features

- User login
- Dashboard with account summary
- Cash transaction management
- Bank transaction management
- Monthly income and expense overview
- User profile and password management

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## Pages

- Login
- Dashboard
- Cash Transactions

## Future Improvements

## Getting Started

1. Clone the repository.
2. Install the required packages.
3. Run the Flask application.
4. Open the application in your browser.
